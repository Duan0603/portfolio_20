## Dự án tiêu biểu

### Cinema Ticket Booking Platform
Nền tảng đặt vé xem phim theo kiến trúc microservices.
- Sơ đồ ghế động, xử lý logic ghế đôi (SweetBox) và định giá động (1.2x VIP, 1.5x SweetBox).
- Microservices với API Gateway (TCP/RabbitMQ), mỗi service một database PostgreSQL riêng.
- Tích hợp cổng thanh toán PayOS với webhook/callback để tự động phát hành vé.
- **Công nghệ:** TypeScript, NestJS, TypeORM, Angular, Tailwind CSS, PostgreSQL, RxJS, Docker Compose, PayOS.

### Smart Waste Sorting System
Hệ thống phân loại rác thông minh chạy AI trên thiết bị edge NVIDIA Jetson.
- Tối ưu model YOLOv8 sang TensorRT (.engine) để tăng tốc suy luận trên Jetson.
- Pipeline CV dùng MOG2 Background Subtraction để kích hoạt suy luận khi có chuyển động.
- Điều khiển servo qua giao thức I2C (PCA9685); dashboard Flask đa luồng stream MJPEG real-time.
- **Công nghệ:** Python, Flask, YOLOv8, PyTorch, TensorRT, OpenCV, Docker, NVIDIA Jetson, PCA9685, I2C, GPIO.

### FitnexusApp
Nền tảng huấn luyện gym online với tính năng AI Trainer. · [GitHub](https://github.com/chipkiet/FitnexusApp)
- AI Trainer dùng YOLOv8-pose nhận diện tư thế và Groq API (Llama) phân tích/gợi ý bài tập.
- Tích hợp cổng thanh toán PayOS cho cả client-side và server-side.
- Áp dụng BMAD Method để chia nhỏ yêu cầu thành các user story nguyên tử.
- **Công nghệ:** JavaScript, React, Node.js, Express.js, YOLOv8-pose, Groq API (Llama), PayOS, Docker.
